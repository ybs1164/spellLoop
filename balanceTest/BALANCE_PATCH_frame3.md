# 2차 밸런스 패치안 (frame3 GA 기준)

근거: GA (`slot_balance_test.py --mode ga --population 30 --generations 40 --eval-seeds 3 --immigrants 0.2 --seed 20261031`, 3단계 심연의 옥좌, build `ceada1ceeb`, 1차 패치 2절 적용 후).
2,593판 / 888조합 (사망 1,859 · 실제 시간 상한 730 · 시간 상한 4 · 클리어 0). 원 데이터 `results/abyss_frame3.csv`, 배율 `results/abyss_frame3_summary.md`.
카드 단위 실행률은 `probe_cards.py`로 앞쪽 300조합(주로 초기 세대)만 120초씩 잰 값이다 (사용자 요청으로 나머지 측정 중단).

## 한계

- **크래시 193판** (`투사체 SoA 슬롯이 바닥났다` 114, `적 SoA 슬롯이 바닥났다` 79). 크래시 판은 CSV에 안 남아 27세대 이후 상위 계통이 빠졌고, 재검증 상위 10개 중 9개가 0으로 나왔다. 후반 세대 배율은 낮은 쪽으로 치우쳐 있다.
- 시간 상한 28%. 상위 조합의 생존·DPS는 과소평가.
- **상위 10조합이 사실상 한 계통**이라 상위 점유율은 의미가 약하다. 그 계통에 얹힌 카드(아래 B-3)는 배율이 부풀려졌다.
- 배율은 슬롯 단위 실행 기준이라, 실행되지 않는 연쇄 구간·꼬리 카드도 셌다 (A-1 참고).

## A. 구조 문제 (수치보다 먼저)

### A-1. 꼬리 카드: 슬롯의 67%가 실행 불가 카드를 달고 있다

마지막 행동 뒤에 행동 없이 놓인 연쇄·대상 카드(예: `전체 | 참격 | 공명의 종`의 공명의 종)는 `slotAnalysis`에서 버려져 **아무 효과 없이 쿨타임만 더한다**. 슬롯 4,440개 중 2,996개(67%)에 있다.

| 카드 | 꼬리 비율 |
|---|---|
| 타격 시 | 76% |
| 외길의 인장 | 76% |
| 공명의 종 | 64% |
| 포위의 뿔피리 | 53% |
| 피의 성배·고요의 모래시계·절제의 반지·질주의 깃털 | 27~31% |
| 플레이어·전방 지점·직전 표적·쓰러진 자리·아이템 (대상) | 22~25% |

제안: `slotRuleError`에 "연쇄 카드 뒤에는 대상과 행동이 있어야 한다"를 넣어 편집기와 GA에서 거부한다 (또는 꼬리 카드를 회색으로 표시하고 쿨타임에서 뺀다). 1차 2-4(실행되지 않는 슬롯 모양)와 같은 항목이다.

### A-2. 조건 연쇄 카드가 연쇄 구간에서는 거의 켜지지 않는다

연쇄 구간의 "슬롯 주인"은 플레이어가 아니라 앞 행동이 만든 탄환·장판·효과 개체다. 조건이 그 개체 기준으로 판정되어 뜻이 바뀐다.

| 카드 | 0구간 실행 | 연쇄 구간 실행 | 원인 |
|---|---|---|---|
| 피의 성배 (체력 절반 이하) | 45/62 | **1/141** | 효과 개체에 체력이 없다 |
| 질주의 깃털 (이동 중) | 32/46 | **2/71** | 장판·효과는 움직이지 않는다 |
| 고요의 모래시계 (멈춤) | **0/12** | 100/210 | 0구간은 플레이어가 자동 조향으로 늘 움직인다 (반대로 연쇄 구간은 대부분 켜짐) |
| 포위의 뿔피리 (주변 적 3) | 11/15 | 27/159 | 효과 위치 기준 |

제안: `when` 조건 카드는 연쇄 구간에서도 **시전 개체(`linkActor`) 기준**으로 판정한다. 그렇지 않다면 설명문을 "이 연쇄를 일으킨 개체"로 바꿔야 한다. 이 수정 후 연쇄 카드 쿨타임을 다시 잰다.

### A-3. 전혀 쓰이지 않는 연쇄·대상 카드

| 카드 | 실행률 | 내용 | 제안 |
|---|---|---|---|
| 외길의 인장 | **0%** (0구간 0/5) | 규칙("행동·대상 1장씩")을 지킨 조합에서도 실행 0회 | 규칙 판정·실행 경로 버그 확인 |
| 타격 시 | 5% (연쇄 14/66) | 첫 칸 금지 + 76% 꼬리 | A-1로 대부분 해결 |
| 아이템 | **0%** (0/44) | 하트·자석·상자가 시야에 거의 없음 | 행동 카드와 맞는 쓰임(흡수 등)이 없으면 보상 풀에서 빼거나 대상 범위 확대 |
| 보석 | 0구간 **0/12**, 연쇄 22/94 | 0구간에서 받는 행동이 맞지 않음 | 보석+자력/흡수 외 조합 거부, 또는 보상 가중치 1 → 0.5 |
| 이벤트 상대 | 0구간 **2/29** | 0구간에는 이벤트가 없다 | 타격 시처럼 0구간 금지 |
| 아군 | 연쇄 **4/80** | 연쇄 구간에서 이어받을 아군이 없다 | 연쇄 구간에서 거부하거나 경고 |
| 쓰러진 자리 | 15% | 1.5초 창이 짧음 | 창 1.5 → 3초 |
| 설치물 | 18% | 같은 덱에 설치 행동이 없으면 빈 대상 | 1차 2-4와 같은 경고 |

## B. 수치 (쿨타임 연산)

규칙은 1차와 같다: 배율 1.25 이상 너프, 0.8 이하 버프, 변경폭 = 현재 × 배율^0.5 (절반 단계, 0.05 반올림).

### B-4. 쿨타임으로 못 고치는 카드 (효과 수치)

+0~+0.2라 쿨타임을 깎아도 안 오른다: 관통탄 0.32 · 표식 0.42 · 끌어당기기 0.42 · 자력 0.21 · 전염 0.74 · 충격파 0.77 · 장판/직전 표적/전방 지점(대상, +0). 1차 5절 제안 유지.

### 배율 변동이 크다

1차(frame) → 2차(frame3) 사이에 속박 1.57 → 0.29, 마탄 1.38 → 0.92, 독 장판 0.17 → 1.55, 궁수 소환 0.27 → 1.84, 보석 0.29 → 1.71. 1차 2절(× → +, 연쇄 상한) 영향과 계통 편승이 섞여 있다. 그래서 전부 절반 단계로만 움직인다.

## C. 수치 밖 문제

- **보스를 못 잡는다.** 보스가 309판에 나왔는데 처치 0, 남은 체력 최소 99.4% (중앙 99.8%). DPS 10만 조합도 보스에는 거의 피해가 없다. 보스 체력·피해 감소·자동 조향(보스 회피) 중 무엇인지 확인 필요. 클리어 0%의 직접 원인.
- **SoA 슬롯 고갈 크래시** — 실전에서도 게임이 멈출 수 있다. `ENEMY_SLOTS` 131072 / `SHOT_SLOTS` 65536, 재사용 지연 240프레임. 고갈 시 throw 대신 생성 거부로 바꾸는 것이 우선.

## 적용 내역 (2026-10-31)

- A-3 중 실행률 0% 카드만: 외길의 인장 쿨타임 +0.45 → +0, 슬롯 행동 효과량 ×1.5 (`actionPower`, 탄속 제외). 아이템 대상 카드 삭제.
- 타격 시: 개체가 만든 투사체(슬롯 행동·`enemyShoot`)의 명중을, 「타격 시」를 듣는 그 개체에도 전한다 (`forwardShotHits`).
- B-1·B-2 쿨타임 그대로 적용. 단 폭발은 피해 비율을 전용 폭발(지뢰·독 장판 점화·유성·화약통)이 같이 써서 피해 대신 쿨타임 +0.1 → +0.15.
- 미적용: A-1·A-2·A-3 나머지, B-3·B-4, C.

## 적용 순서

1. C (보스 확인, SoA 고갈 시 생성 거부) — 측정 자체가 깨지는 문제.
2. A-1 꼬리 금지, A-2 조건 판정 기준, A-3 인장 버그·0구간 이벤트 상대 금지.
3. B-1·B-2 적용 → GA 재측정 → B-3 판정.
