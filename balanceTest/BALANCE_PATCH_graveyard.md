# 묘역 단일 슬롯 밸런스 패치안

데이터: `results/graveyard_single_slot.csv` 4,535회 중 피해 0 (3,956회)을 뺀 579회.
클리어 15회 / 피해 상위 30개 조합 기준.

## 1. 사기 조합

| 순위 | 조합 | 근거 |

## 2. 원인

1. **흡수가 적에게도 즉사기.**
   - `ACTION_RULES.absorb` 는 `requires: position, exclude: self/point` 라서 `enemy` 도 통과한다 (js/cards.js:539).
   - 카드 선언의 `accepts` 는 `object/ally/zone/shot/gem` 이지만, `requires` 가 있으면 `accepts` 를 보지 않는다 (cards.js:77-80).
   - `consumeTarget` → `killEnemy` 가 보스 여부, HP, 면역을 보지 않는다 (game.js:756, 1568).
   - 결과: 보스 HP 528,000도 코스트 1짜리 카드로 즉사. 클리어 15개의 `boss_damage` 가 전부 528,000으로 동일.
2. **광역 대상 `enemies`(코스트 6)가 적 수와 무관한 고정 가격.**
   - 시야 600 안의 모든 적에게 행동을 적용한다.
   - 이 맵은 동시 적 수가 400 안팎이라 행동 하나가 사실상 ×수백 배가 된다.
   - `enemies` 포함 조합의 중앙 DPS 750으로 평균(178)의 4배.
   - `all` 도 같은 문제 (DPS 882, 코스트 5).
3. **카드 코스트 대비 피해 불균형.**
   - 흡혈: 피해 60, 코스트 2 (마탄 20/1, 참격 24/2, 폭발 26/2). 광역과 결합한 중앙 DPS 1316으로 `enemies` 조합 중 최고.
   - 산탄: 60, 코스트 2. 유도탄: 60, 코스트 2.
   - 흡혈은 피해 외에 회복도 있어 생존까지 같이 해결. 코스트 6 이상 조합에서 2코스트 행동이 DPS를 가장 많이 올린다.
4. **표식 중첩에 상한이 없음.**
   - 중첩당 +90% 가산이고 상한이 없다 (entities.js:29-31, game.js:797-809).
   - 쿨이 짧은 조합일수록 중첩이 무한히 쌓여 피해가 배수로 늘어난다.

## 3. 패치안

1. **흡수 (필수)**
   - `ACTION_RULES.absorb.exclude` 에 `'enemy'` 추가. 흡수는 소환물·장판·투사체·아이템 전용으로 되돌린다 (선언한 `accepts` 와 일치).
   - 방어적으로 `consumeTarget` 에서 `Enemy` 는 `killEnemy` 대신 return.
   - 그 뒤 `accepts` 우회 가능성이 있는 다른 `requires` 기반 규칙도 점검 (`split`, `swap`, `blink`, `dash`).
2. **`enemies` / `all` 대상 (핵심)**
   - 선택안 A: 대상이 3개를 넘으면 행동 위력을 `1/√(대상 수)` 로 줄이는 광역 감쇠.
   - 선택안 B: 시야 600 → 300 으로 줄이고, 코스트 6 → 8 (`all` 5 → 8).
   - 권장: A를 먼저 적용. B는 단독으로는 DPS 감소가 불확실하다.
3. **흡혈 / 산탄 / 유도탄**
   - 흡혈: 피해 60 → 36, 회복 0.06 → 0.04.
   - 산탄: 60 → 40.
   - 유도탄: 60 → 40 (유도 보너스 감안).
   - 목표: 코스트 2 단일 행동 피해를 24~40 범위로 모음.
4. **표식**
   - 중첩 상한 5 (최대 +450%), 또는 중첩당 +90% → +40%.
   - 표식 6초 지속 중 재적용 시 갱신 방식으로 변경 검토.
5. **`self + shockwave + mark` (B)**
   - 원인 확정 후 별도 처리. 먼저 `casts_per_min` 610의 출처 (자기 표식이 이벤트를 발생시켜 재시전되는지)를 `tools/` 의 로그로 확인.

## 4. 검증

- 패치 후 같은 시뮬레이터를 최소 2,000회 이상 재실행.
- 합격선:
  - 클리어 비율이 현재 0.33%에서 소폭 상승 정도 (보스는 정직하게 싸워야 함).
  - 피해 > 0 조합에서 상위 5% DPS 대 중앙값 DPS 비율 ≤ 8배.
  - `absorb` 가 포함된 조합의 클리어 점유율 < 30%.
