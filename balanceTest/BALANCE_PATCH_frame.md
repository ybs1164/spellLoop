# 기본 슬롯 쿨타임 0.016 밸런스 패치안

변경 전제: `BASE_COOLDOWN` 1 → 0.016 (js/cards/cooldown.js). 슬롯 쿨타임 = 0.016에 카드 연산을 배치 순서대로 적용.

근거: GA (`slot_balance_test.py --mode ga --population 30 --eval-seeds 3 --immigrants 0.2 --seed 20261024`, 3단계 심연의 옥좌, build `08d49ebbd2`)
0~27세대 2,113판 / 705조합 (사망 1,796 · 시간 상한 305 · 클리어 12). 원 데이터 `results/abyss_frame.csv`, 요약 `results/abyss_frame_summary.md`.

배율 = 카드가 들어간 조합 평균 ÷ 전체 평균 (n ≥ 25). 평균 DPS 38,486 / 평균 생존 87초.
**실행된 슬롯의 카드만 센다** (`probe_slots.py`로 조합마다 90초 다시 돌려 슬롯별 실행 횟수를 잼, `analyze_ga.py --activity`). 이유는 1절.

계획은 100세대였으나 세대당 시간이 5분(15세대) → 18분(22세대)으로 늘어 27세대에서 끊었다 (5절).

## 한계

- 레벨업·보상 없이 고정 덱으로 3단계를 바로 돈다. 실전보다 생존이 짧고, 생존 배율은 DPS 배율을 따라간다.
- **상위 조합은 DPS가 포화됐다.** 서로 다른 상위 8계통이 200초 기준 DPS 94,000~97,600으로 거의 같고, 2절 구조 수정을 넣어도 −0~6%만 변한다. 나오는 적을 모두 녹여서 DPS가 스폰 체력 총량에 막힌 것으로 보인다. 상위권 비교에는 DPS보다 보스 처치 시간·받은 피해가 맞다 (6절).
- 20~26세대 판의 41%가 실제 시간 상한(180초)에 걸려 중간에 끊겼다. 상위 조합의 생존은 과소평가된 값이다.
- 슬롯 실행 여부는 처음 90초만 쟀다. 체력 절반 이하(피의 성배)처럼 늦게 켜지는 슬롯은 실행 0회로 잡혔을 수 있다.
- 그래서 2절(구조)을 먼저 넣고 다시 측정한 뒤 3~4절 수치를 확정하는 2단계로 제안한다.

## 1. 측정 결과 요약

### 연쇄 기믹은 GA에 적용되어 있다

`check_ga_chain.py` 통과: 무작위 슬롯의 60%가 연쇄 구조, 타격 시 → 번개 / 2단 연쇄 / 조건 연쇄(뿔피리) 모두 실제 실행, 연쇄를 붙이면 DPS 상승 (마탄 315 → 마탄·타격 시·번개 2,210).

| | 조합 | 평균 DPS | 평균 생존 |
|---|---|---|---|
| 연쇄가 실제 실행된 조합 | 454 (64%) | 55,235 | 113초 |
| 연쇄 슬롯은 있으나 한 번도 실행 안 됨 | 251 | 8,192 | 40초 |

상위 10% 조합은 연쇄 슬롯 평균 2.4개, 한 판에 연쇄 실행 약 38만 회. 최상위 조합은 주력 슬롯 한 개가 시전 122회로 연쇄 16만 회를 일으킨다 (시전 1회당 약 1,300회).

### 슬롯의 46%가 실행되지 않는다 (편승 카드)

- 705조합 중 655개에 실행 0회 슬롯이 있고, 전체 슬롯 3,525개 중 46%가 처음 90초 동안 한 번도 실행되지 않았다.
- 최상위 조합도 5슬롯 중 3개가 실행 0회다. 실제 DPS는 `전체 | 마탄 | 뿔피리 | 적 | 저격 | 행동 완료 시 | 장판` 한 슬롯에서 나온다.
- 실행 0회가 되는 대표 모양:
  - `타격 시`로 시작하는 슬롯: 앞 행동이 없어 발동 이벤트가 오지 않는다 (`행동 완료 시`로 시작하면 정상 작동).
  - `타격 시 | 플레이어 | 위치 교환`: 위치 교환은 자기 자신을 대상에서 제외한다 (`exclude: ['self']`).
  - `설치물`·`장판`을 대상으로 하는데, 같은 덱에 그것을 만드는 슬롯이 없는 경우.
- 적합도에 영향이 없는 슬롯은 강한 계통에 얹혀 퍼진다. 전체 카드 기준으로 세면 위치 교환 1.82 · 전염 1.37로 1·4위였지만, 실행된 슬롯만 세면 0.70 · 0.82다.

### 쿨타임 분포

- 슬롯 쿨타임 중앙값 1.65초, 0.1초 이하 5%, 1초 이상 71%. 연쇄 스택은 뒤 카드의 연산까지 모두 쌓이므로 길어진다.
- 0.016 기본값의 영향은 × 연산에서 가장 크다: `전체 ×3.5`를 맨 앞에 두면 0.016 × 3.5 = 0.056초.

## 2. 구조 수정 (1단계, 수치보다 먼저)

| # | 문제 | 근거 | 수정안 |
|---|---|---|---|
| 2-1 | **연쇄 실행에 상한이 없다.** 연쇄 슬롯은 쿨타임 없이 앞 행동이 맞힐 때마다 실행된다. 광역 다단 히트 + 연쇄가 초당 500~1,000회 | 연쇄 실행 조합 DPS 6.7배, 20세대 이후 판당 연산 시간 93초·41% 시간 초과, 상위 계통 DPS 포화 | 플레이어 연쇄 슬롯마다 프레임당 실행 상한 (제안 8회, 넘친 이벤트는 버림). 기존 `CARD_EVENT_BUDGET`에 연쇄 슬롯을 포함하는 방식도 가능 |
| 2-2 | **× 연산이 슬롯 앞에 오면 거의 공짜.** GA는 `전체`를 맨 앞에 둔다 | 전체 1.57 · 저격 1.63 · 적 1.18, 셋 다 상위 100% | × 를 + 로: 전체 ×3.5 → **+1.2**, 적 ×3 → **+0.9**, 저격 ×1.8 → **+0.6**. 단일 `가장 가까운 적 + 마탄` 0.32초 대비 광역 `전체 + 마탄` 1.32초 (4.2배). 대표 슬롯 쿨타임 1.65 → 2.97초 |
| 2-3 | 연쇄 이벤트 카드 쿨타임 +0 | 행동 완료 시 1.26 (상위 100%) | 행동 완료 시 +0 → **+0.15**, 타격 시 +0 → **+0.2** (연쇄를 쌓을수록 본 슬롯이 느려지게) |
| 2-4 | **실행되지 않는 슬롯 모양을 막지 않는다** | 슬롯 46% 실행 0회 | 편집기에서 `타격 시`·`행동 완료 시`를 슬롯 첫 칸에 놓지 못하게 하거나 (슬롯 주인 기준 이벤트로 바꾸거나), 실행될 수 없는 슬롯에 경고를 표시. 위치 교환 + 플레이어 조합도 규칙에서 거부 |
| 2-5 | +0 행동 카드는 혼자 두면 매 프레임 | 실행된 슬롯 기준으로는 과강 아님 (자력 1.58만 높음) | 자력 +0 → +0.15. 나머지(산탄·소용돌이·끌어당기기·전염·위치 교환)는 재측정 후 결정 |

미리 보기 (`preview_patch.py --cd all=+1.2,enemies=+0.9,snipe=+0.6,on_hit=+0.2,on_complete=+0.15`, 상위 8계통 × 시드 3개 × 200초):
DPS −0~6% (중앙값 0.97배), **초당 연쇄 실행 −10~39%**. DPS가 포화돼 거의 안 변하므로 2-2·2-3은 상위권 DPS보다 성능과 중위권 격차에 효과가 있다. 상위권은 2-1 없이는 내려오지 않는다.

## 6. 성능 위험 (실전 프레임)

- 세대가 오를수록 판당 연산 시간이 19초(0~9세대) → 24초(10~19) → 93초(20~26)로 늘었다. 초당 연쇄 실행도 21 → 151 → 605회.
- 시간 상한 비율 3% → 4% → 41%. 같은 조합이면 실제 게임도 프레임이 떨어질 가능성이 높다.
- 노드 워커가 V8 메모리 부족(Zone OOM)으로 2번 죽었다. 같은 조합을 새 프로세스에서 돌리면 재현되지 않아, 오래 쓴 워커의 누적 문제로 보인다 (GA는 재시도하도록 수정).
- 2-1(연쇄 실행 상한)이 밸런스·성능을 함께 잡는 핵심 항목이다.

## 7. 적용·검증 순서

1. 2절 구조 수정 적용 → `node tools/run-all-checks.cjs` → 기준선 갱신.
2. GA 적합도 보완: DPS 포화 구간은 보스 처치 시간·받은 피해로 비교하게 한다 (예: DPS 구간 `--dps-tie`를 크게, 동률이면 보스 처치 시간).
3. 새 결과 파일로 GA 20~30세대 (`--out balanceTest/results/abyss_frame2.csv`, 이제 `slot_runs` 열이 기록됨) → `analyze_ga.py`로 배율 재측정.
4. 3~4절 수치를 재측정 배율로 보정해 적용 (1.25 이상 너프, 0.8 이하 버프, 절반 단계). `preview_patch.py --cd …`로 상위 계통 영향을 미리 확인.
5. 5절 카드는 별도 효과 수치 패치.
6. 목표: 행동 카드 DPS 배율 0.7~1.4, 상위 조합 점유 80% 이상 카드 없음, 시간 상한 비율 10% 이하, 실행 0회 슬롯 비율 10% 이하.
