# 6슬롯 GA 기반 밸런스 패치안 (쿨타임·타입만)

근거: `results/graveyard_6slot.csv` — 망자의 묘역, 이동 슬롯 + 진화 슬롯 5칸, 27세대, 974조합 / 2921판 (클리어 113, 600초 생존 1014, 사망 1130, 실시간 상한 664).
최고 조합은 DPS 25.7k, 600초 생존(타임아웃)이고, 전 조합 평균은 DPS 5.7k / 생존 388초다.

슬롯 쿨타임 = 기본 1초에 아티팩트 → 대상 → 행동 순으로 연산 적용. 앞의 ×는 뒤의 대상 ×3 / ×3.5 에 같이 곱해진다.

## 1. 관찰

1위 조합은 전부 비슷한 구조다.

- 아티팩트: 공명의 종 · 포위의 뿔피리 · 고요의 모래시계 (곱셈형 ×0.5~0.55, 두 장 겹치면 ×0.3).
- 대상: 플레이어 / 아군 / 전체 / 적 같은 다중 대상.
- 행동: 버프·유지형(치유 · 보호막 · 갱신 · 격려 · 집중 · 분노 · 미끼)에 관통탄 · 화상 · 부유 구체를 더한 조합.
- 5칸이 전부 쿨타임 1~6초로 계속 돌아서 지속시간이 5~6초인 버프가 항상 켜져 있다.

## 4. 타입(구성 규칙) 조정 제안

- 공명의 종 (`eventKind: complete`): 6슬롯에서는 다른 슬롯이 늘 작동하므로 조건이 무의미하다. 같은 슬롯 안에서만 발동하게 바꾸거나 같은 슬롯에 두 장 이상 못 넣게 제한한다.
- 곱셈형 아티팩트 중복(뿔피리 + 모래시계): 한 슬롯에 곱셈형 아티팩트를 1장만 허용하는 `rule` 추가를 검토한다. 현재 최상위 조합은 두 장을 겹쳐 ×0.3 이다.
- 외길의 인장(-0.45): 표본이 17개뿐이라 판단 보류.

## 5. 적용 후 재측정

`python balanceTest/slot_balance_test.py --mode ga --population 40 --generations 0 --eval-seeds 3 --actions 1-4 --targets 1-2 --artifacts 0-2 --out balanceTest/results/graveyard_6slot.csv`

빌드 해시가 바뀌면 캐시가 새로 쌓인다. 기존 CSV 는 이전 빌드 기록으로 남는다.

## 6. 알려진 문제

- 일부 조합에서 Node 워커가 메시지 없이 종료(code 1)하거나 힙 부족으로 죽는다 (`results/worker_crashes.log`). 5칸 소환·설치물이 누적되는 조합으로 보이며, 개체 수 상한 점검이 필요하다.
- 실시간 상한(180초)에 걸린 판이 23%다. 이 판의 DPS 는 중간까지만 반영된다.
