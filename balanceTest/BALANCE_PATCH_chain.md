# 연쇄 시스템 GA 기반 밸런스 패치안 (쿨타임·쿨타임 조정 타입만)

근거: `results/graveyard_chain.csv` — 망자의 묘역, 이동 슬롯 + 진화 슬롯 5칸(대상 → 행동 → 연쇄 순환, 최대 9장), GA 0~11세대, 919판 (사망 501, 600초 생존 401, 클리어 17). 전체 평균 DPS 3,140 / 생존 316초.
방법: 카드가 들어간 조합의 평균 ÷ 전체 평균 (n ≥ 25). 쿨타임은 기본 1초에 카드 연산을 배치 순서대로 적용한 값이다.

주의: GA 가 수렴하며 약한 카드는 표본이 줄고, 강한 카드와 함께 쓰인 효과가 섞인다. 방향은 맞지만 수치는 한 번에 크게 옮기지 말고 단계적으로 보정한다. 카드 성능 자체(피해량 등)는 건드리지 않고 쿨타임 연산만 바꾼다.

## 4. 적용 순서

1. 너프·연쇄 카드 조정(1~2절)을 먼저 적용하고 GA 를 새 빌드로 이어서 돌려, 상위 조합에서 유성·분노·보석 편중이 줄었는지 확인한다.
2. 약한 카드는 3절의 절반 수준만 먼저 적용한다 (n 이 작아 과대 추정 위험). 쿨타임만으로 안 오르는 카드(공포·격려·회전 칼날)는 이후 효과 수치 조정으로 넘긴다.
