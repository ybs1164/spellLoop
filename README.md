# Spell Loop

카드를 조합해 반복 발동하는 스킬을 만들고 몬스터 무리에서 살아남는 웹 게임입니다.

## 실행

저장소를 내려받은 뒤 `index.html`을 브라우저에서 열면 실행됩니다.

## 슬롯 실행

슬롯은 서로 기다리지 않고 각자 실행되며, 쿨타임이 끝난 슬롯은 바로 다시 실행됩니다. **E/Tab**은 카드 편집, **Esc**는 일시정지입니다.

대상 조건은 대상 카드에 포함됩니다. **가장 가까운 적**은 적 하나, **마무리 대상**은 체력이 30% 이하인 적들을 고릅니다. **전체**는 거리 제한 없이 현재 존재하는 플레이어·적·설치물·아군·장판·양측 탄환·보석·아이템을 모두 고릅니다. 전방 지점처럼 카드가 생성하는 좌표는 실제 개체가 아니므로 전체 목록에 추가하지 않습니다.

대상의 **체력·범위·위치·제한시간**은 각각 ON/OFF 속성으로 판단합니다. 치유·보호막·재생·철갑은 체력이 있는 대상, 증폭은 범위가 있는 대상, 연장·갱신은 제한시간이 있는 대상에 적용됩니다. 자신에게 사용하는 버프는 기존처럼 주문 능력치를 강화합니다. 도주 중인 보물 상자도 제한시간을 연장하거나 갱신할 수 있습니다. 코드에서 개체의 `targetFeatures`에 속성별 불리언 값을 지정하면 자동 판정을 덮어씁니다.

**기폭·사출·희생·흡수**는 자신과 지점을 제외한 모든 개체를 소모합니다. 적에게 사용하면 처치로 처리되고, 흡수한 보석·아이템은 바로 획득합니다. **분열**은 보석·아이템에도 적용되며 보석의 경험치 합계는 유지됩니다.

검증: `node tools/check-card-costs.cjs`, `node tools/check-targets.cjs`, `node tools/check-slots.cjs`, `node tools/check-enemy-damage.cjs`.
