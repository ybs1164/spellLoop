## 🎯 게임 목표

- 한 판은 **3단계**로 진행됩니다. 단계마다 테마 스테이지 8종 중 하나가 무작위로 정해집니다.
- 3분 30초~4분이 지나면 **보스**가 등장합니다. 쓰러뜨리면 다음 단계로, **3단계 보스를 쓰러뜨리면 승리**입니다.
- 1분마다 **포위 공격**이 몰려옵니다. 적을 처치해 경험치를 모으고, 체력이 0이 되기 전에 빌드를 완성하세요.

## 🕹️ 조작

| 조작 | 키 |
| --- | --- |
| 이동 | `W` `A` `S` `D` / 방향키 |
| 카드 편집 | `E` / `Tab` |
| 보상 목록 열기/닫기 | `R` |
| 보상 카드 선택 | `1` ~ `5` |
| 개체 조회 (적·아군 슬롯 보기) | `I` |
| 일시정지 | `Esc` / `P` |
| 소리 켜기/끄기 | `M` |
| 성능 오버레이 | `F3` |

**공격은 자동입니다.** 플레이어는 이동과 **카드 조합**에 집중합니다. 이동조차 `바람의 장화 → 플레이어 → 입력 방향 이동` 카드로 만든 슬롯이 매 프레임 실행하는 것입니다.

### 🃏 카드로 주문 만들기

![editor](docs/editor.png)

플레이어는 **6개의 슬롯**을 가지며(맨 앞은 이동 슬롯), 한 슬롯에 카드를 최대 9장까지 **대상 → 행동 → 연쇄 → 대상 → 행동 …** 순서로 쌓습니다. 연쇄 카드는 앞 행동의 결과를 이어받아 뒤의 대상·행동을 실행합니다.

| 칸 | 역할 | 예시 |
| --- | --- | --- |
| 대상 | 누구에게 쓸지 | `가장 가까운 적`, `마무리 대상`, `전방 지점`, `이벤트 상대`, `전체` |
| 행동 | 무엇을 할지 | `마탄`, `번개`, `빙결`, `유성`, `부유 구체`, `기사 소환`, `분열` |
| 연쇄 | 앞 행동을 잇거나, 슬롯에 조건·제약을 검 | `타격 시`, `행동 완료 시`, `가시 갑옷`(피격 순간), `피의 성배`(체력 절반 이하), `절제의 반지`(행동 3장 이하) |

모든 슬롯은 **쿨타임**마다 작동합니다. 쿨타임은 기본 0.016초(매 프레임)에서 시작해 카드마다 붙은 연산(`+`, `×`, `=`)을 놓인 순서대로 더해 갑니다. 카드를 많이 쌓을수록 강해지지만 느려집니다.

- `가장 가까운 적 → 마탄` — 0.016 + 0.2 + 0.1 = **0.316초**마다 사격
- `가장 가까운 적 → 마탄 → 타격 시 → 이벤트 상대 → 번개` — 마탄이 맞힐 때마다 그 적에서 번개 연쇄
- `절제의 반지 → 가장 가까운 적 → 마탄` — 반지 +0.6, 행동 3장 이하일 때만 넣을 수 있음
- `가시 갑옷 → 플레이어 → 치유` — 피격되는 순간에만, 쿨타임이 끝났으면 회복
- `바람의 장화 → 플레이어 → 입력 방향 이동` — `=0.016`으로 매 프레임 이동

플레이어뿐 아니라 **적·보스·아군·설치물·탄환까지 모두 같은 슬롯과 카드 스택**으로 움직입니다. `I` 키로 아무 개체의 슬롯을 열어 볼 수 있습니다.

### ⬆️ 성장

![levelup](docs/levelup.png)

- 레벨업·보물 상자마다 **보상 카드 5장 중 하나**를 고릅니다. 게임은 멈추지 않고 보상이 우측 상단에 쌓이니, `R`로 열어 원할 때 고르세요.
- 보상으로 나오는 카드는 **69종**(대상 18 · 행동 41 · 연쇄 10)이며 코스트가 없습니다.
- 카드 편집기에서 슬롯 구성을 언제든 바꿔 빌드를 재설계할 수 있습니다.
- 아군·설치물(기사, 궁수, 포탑, 미끼, 지뢰 등)을 소환하는 것도 전략입니다.

### 👹 보스와 스테이지

![boss](docs/boss.gif)

| 단계 | 스테이지 (보스) |
| --- | --- |
| 1 | 슬라임 둥지 (슬라임 왕) · 이끼 온실 (재생의 모체) · 박쥐 병영 (군단의 지휘자) |
| 2 | 망자의 묘역 (망령 군주) · 봉인된 성소 (속박의 예언자) · 철벽 요새 (철벽의 수문장) |
| 3 | 잿불 화구 (잿불의 폭군) · 심연의 옥좌 (심연 군주) |

보스는 출현 배너에 공략 힌트가 뜨고, 일시정지 화면과 **도감**에서 다시 볼 수 있습니다. 단계마다 배경 음악이 바뀌며, 화약통 같은 변수도 숨어 있습니다.

## 🚀 실행

설치 없이 저장소를 내려받아 `index.html`을 브라우저로 열면 됩니다(순수 JS·Canvas, 빌드 도구 없음).

```bash
git clone https://github.com/ybs1164/spellLoop.git
```

로컬 서버로 열려면(Node.js):

```bash
npm run serve
```

`http://localhost:8123`에서 실행됩니다. 적·탄환 1만 개가 넘는 장면도 C/WASM 커널과 이벤트 예산으로 한 프레임 16ms 안에 돌아갑니다(`npm run bench`).
