## 🎯 게임 목표

- 한 판은 **3단계**로 진행됩니다. 단계마다 테마 스테이지 8종 중 하나가 무작위로 정해집니다.
- 시간이 지나면 **보스**가 등장합니다. 쓰러뜨리면 다음 단계로, **3단계 보스를 쓰러뜨리면 승리**입니다.
- 몰려오는 적을 처치해 경험치를 모으고, 체력이 0이 되기 전에 빌드를 완성하세요.

## 🕹️ 무엇을 할 수 있나

| 조작 | 키 |
| --- | --- |
| 이동 | `W` `A` `S` `D` / 방향키 |
| 카드 편집 | `E` / `Tab` |
| 일시정지 | `Esc` |
| 레벨업 카드 선택 | `1` `2` `3` |
| 성능 오버레이 | `F3` |

**공격은 자동입니다.** 플레이어는 이동과 **카드 조합**에 집중합니다. 6개의 슬롯은 각자의 **쿨타임**(기본 1초)마다 작동하며, 슬롯 카드마다 붙은 쿨타임 연산(`+`, `−`, `×`, `=`)이 배치 순서대로 쿨타임을 바꿉니다.

### 🃏 카드로 주문 만들기

![editor](docs/editor.png)

플레이어 슬롯은 카드 한 줄이며, 처음 놓은 카드를 기준으로 **대상 → 행동 → 연쇄 → 대상 → 행동 …** 순서가 반복됩니다 (빈 칸은 다음 순서의 종류만 받음). 연쇄 카드는 앞 행동의 결과를 이어받아 뒤의 대상 카드에 뒤따르는 행동을 실행시킵니다 (예: `가장 가까운 적 → 탄환 → 타격 시 → 이벤트 상대 → 빙결`). 쿨타임 연산은 놓인 순서대로 적용됩니다.

| 칸 | 역할 | 예시 |
| --- | --- | --- |
| 연쇄 | 앞 행동의 결과(`타격 시`, `행동 완료 시`, `피격 시`)를 잇고, 슬롯에 제약을 걸고 쿨타임을 바꿈 | `바람의 장화`(이동 카드 슬롯 전용, =0.016), `절제의 반지`(행동 3장 이하, ×0.5), `피의 성배`(체력 절반 이하일 때만, ×0.3) |
| 대상 | 누구에게 쓸지 | `가장 가까운 적`, `마무리 대상`, `전체`, `자신` |
| 행동 | 무엇을 할지 | `탄환`, `빙결`, `연쇄`, `치유`, `보호막`, `흡수`, `분열` |

조합 예시:

- `가장 가까운 적 → 마탄` — 쿨타임 1 + 0 − 0.2 = 0.8초마다 사격
- `절제의 반지 → 가장 가까운 적 → 마탄` — 1 × 0.6 + 0 − 0.2 = 0.4초
- `가시 갑옷 → 자신 → 치유` — 피격될 때만, 쿨타임이 끝났으면 회복
- `가장 가까운 적 → 마탄 → 번개` — 마탄의 타격마다 번개 연계
- `바람의 장화 → 플레이어 → 입력 방향 이동` — 매 프레임(=0.016) 이동하는 기본 이동 슬롯

### ⬆️ 성장

![levelup](docs/levelup.png)

- 레벨업·보물 상자마다 **카드 5장 중 하나**를 고릅니다. 카드에는 코스트가 없습니다.
- 슬롯은 **6개로 고정**이며, 맨 앞이 이동 슬롯입니다.
- 카드 편집기에서 슬롯 구성을 언제든 바꿔 빌드를 재설계할 수 있습니다.
- 아군·설치물(포탑, 미끼, 지뢰 등)을 소환하는 것도 전략입니다.

### 👹 보스와 스테이지

![boss](docs/boss.gif)

| 단계 | 스테이지 (보스) |
| --- | --- |
| 1 | 슬라임 둥지 (슬라임 왕) · 이끼 온실 (재생의 모체) · 박쥐 병영 (군단의 지휘자) |
