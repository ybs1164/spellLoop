# Spell Loop

넉백 저항과 기본 수명은 모든 개체의 공통 스탯이며, 수명은 카드 없이도 만료됩니다. 플레이어는 편집·확장 슬롯과 별도로 매 프레임 화살표/WASD 입력을 실행하는 고정 이동 슬롯을 가집니다. 화약통의 자동 점화·연쇄 반응·기본 사망 폭발은 제거했으며, 분열 복제는 원본의 현재 카드 스택을 계승하고 슬롯과 쿨타임 저장소를 독립적으로 가집니다. 플레이어 분신도 입력 이동과 스킬을 계승하되 기본 수명은 10초입니다. 검증: `node tools/check-basic-state-inheritance.cjs`.

개체 세부 수치 저장소를 제거하고 최대 체력 같은 기본 상태와 실제 행동 카드로 대체했습니다. 피해 배율·탄속·발수·공전·보상은 카드가 소유하며, 보스·기믹도 같은 조건·대상·주기·행동 규칙으로 실행합니다. 전환 기준: [개체 상태와 행동 카드](reports/entity-state-migration.md).

3단계 진행 · 보스 스테이지 8종: 한 판은 1 → 2 → 3단계로 진행하고, 단계마다 해당 단계 스테이지 중 하나가 무작위로 정해집니다. 보스를 쓰러뜨리면 다음 단계로 넘어가고 3단계 보스를 쓰러뜨리면 승리합니다. 1단계 슬라임 둥지(슬라임 왕·분열) · 이끼 온실(재생의 모체·회복) · 박쥐 병영(군단의 지휘자·격려) / 2단계 망자의 묘역(망령 군주·소환) · 봉인된 성소(속박의 예언자·표식·속박) · 철벽 요새(철벽의 수문장·방패·갑주) / 3단계 잿불 화구(잿불의 폭군·화염 탄막) · 심연의 옥좌(심연 군주·갑주 탄막). 출현 배너와 일시정지 화면에서 빌드별 공략 힌트를 확인할 수 있습니다. 검증: `node tools/check-gimmick-bosses.cjs`.

카드를 조합해 반복 발동하는 스킬을 만들고 몬스터 무리에서 살아남는 웹 게임입니다.

## 슬롯 실행

시작 시 코스트 포인트 5를 받고 레벨업마다 1포인트를 얻습니다. 카드 편집기에서 3포인트로 슬롯을 언제든 확장할 수 있습니다(최대 6개).

모든 슬롯(플레이어·개체)은 **조건 카드 슬롯 → 대상 카드 슬롯 → 행동 카드 슬롯** 세 칸으로 나뉘며 이 순서로 실행됩니다. 카드는 자기 종류의 칸에만 놓이고, 대상 칸의 여러 대상 카드는 같은 조건을 적용한 뒤 대상을 합쳐 행동 칸의 행동을 모두 받습니다. 개체의 주기·충돌 대상 카드도 조건 칸에 놓입니다. 카드 편집기에서 플레이어가 아닌 개체의 카드 슬롯은 닫힌 상태가 기본이며 눌러서 열고 닫을 수 있습니다(도감도 동일). 검증: `node tools/check-slot-sections.cjs`.

슬롯은 서로 기다리지 않고 각자 실행되며, 쿨타임이 끝난 슬롯은 바로 다시 실행됩니다. **E/Tab**은 카드 편집, **Esc**는 일시정지입니다.

한 행동의 여러 대상은 같은 프레임에 동시에 적용됩니다. 행동당 대기는 한 번이며, 기존 대상별 대기시간은 슬롯의 추가 쿨타임으로 옮깁니다. 예를 들어 딜레이 0.2초인 행동이 3개 대상에게 적용되면 0.2초만 기다리고 슬롯 쿨타임에 0.4초를 더합니다. 죽었거나 적용할 수 없는 대상은 추가 쿨타임에 포함하지 않습니다. 기본 쿨타임도 실제 실행 기준입니다: `(대상 카드 비용 × 행동을 받은 대상 수 / 처음 선택한 살아 있는 대상 수 + 실행한 행동 카드 비용 합) × 0.35초`, 최소 0.6초에 추가 대상 쿨타임을 더합니다. 대상 비용은 묶음마다 계산하며 같은 대상에 여러 행동을 써도 중복 계산하지 않습니다. 필터 비용은 슬롯 제한에만 반영되고 쿨타임에는 포함되지 않습니다. 아무 행동도 실행되지 않으면 0.5초 뒤 다시 확인합니다.

대상 카드로 기본 대상을 선택하고 필터 카드로 조건에 맞는 대상만 남깁니다. **가장 가까운 적**은 적 하나, **마무리 대상**은 체력이 30% 이하인 적들을 고릅니다. **전체**는 거리 제한 없이 현재 존재하는 플레이어·적·설치물·아군·장판·양측 탄환·보석·아이템을 모두 고릅니다. 전방 지점처럼 카드가 생성하는 좌표는 실제 개체가 아니므로 전체 목록에 추가하지 않습니다.

대상의 **체력·범위·위치·제한시간**은 각각 ON/OFF 속성으로 판단합니다. 치유·보호막·재생·철갑은 체력이 있는 대상, 증폭은 범위가 있는 대상, 연장·갱신은 제한시간이 있는 대상에 적용됩니다. 증폭은 대상 자체의 크기·범위만 바꾸고, 연장은 그 대상의 남은 시간만 바꿉니다. 분노는 공격 가능한 대상의 피해와 보석의 경험치 가치를 5초간 50% 높이고, 집중은 궁수·포탑·발사형 적의 공격 간격을 5초간 35% 줄이며 플레이어의 이후 주문 능력치를 바꾸지 않습니다. 도주 중인 보물 상자도 제한시간을 연장하거나 갱신할 수 있습니다. 코드에서 개체의 `targetFeatures`에 속성별 불리언 값을 지정하면 자동 판정을 덮어씁니다.

아군과 설치물도 체력이 있는 대상입니다. 기본 체력은 각각 50이며 체력과 수명은 별도로 관리됩니다. 피해·치유·재생·보호막·철갑이 적용되고 체력이 0이 되면 사라집니다. 도감의 행동 카드는 효과 종류 대신 적용에 필요한 대상 속성에 따라 **체력을 가진 대상·범위를 가진 대상·위치를 가진 대상·제한시간을 가진 대상**으로 분류합니다. 이 속성들은 카드마다 ON/OFF 표시로 붙이지 않습니다.

공격·상태이상·치유는 선택한 대상에 직접 적용됩니다. 자력은 선택한 보석·아이템만 끌어오고, 이동 행동은 선택한 개체 자체를 옮깁니다. 실제 개체에 붙인 독 등의 지속 효과는 그 대상에만 적용되며, 지점에 설치한 장판은 해당 위치에서 기존 범위 효과를 냅니다. 회전 칼날은 선택한 대상 주위를 돌며 각 칼날에 충돌한 적에게 피해를 줍니다.

조건 카드는 **조건 → 대상 → 행동** 순서로 배치됩니다. 조건은 대상 칸의 대상 카드에 적용되며, 여러 조건은 모두 만족해야 합니다. 대상 카드만 쓰거나 제어 카드와 함께 쓰더라도 실행 가능한 대상이 없으면 슬롯을 시작하거나 쿨타임을 걸지 않습니다. 기본 조건은 체력·거리·방향·주변 적·사망·표식·빙결/속박·화상·강적·대상 수 15종입니다. 거리·방향은 슬롯 주인 기준이고 상태 조건은 직접 적용 상태도 확인합니다. `불타고 있을 때`는 화염 특성과 점화된 화약통도 포함합니다. 예: `부상일 때 → 자신 → 치유`, `적이 근처일 때 → 설치물 → 격려`, `표식이 있을 때 → 적 → 저격`, `사망 시 → 슬롯 주인 → 폭발`.

**흡수**는 자신과 지점을 제외한 모든 개체를 소모합니다. 적에게 사용하면 처치로 처리되고, 흡수한 보석·아이템은 바로 획득합니다. **분열**은 보석·아이템에도 적용되며 보석의 경험치 합계는 유지됩니다.

검증: `node tools/check-controls.cjs`, `node tools/check-card-costs.cjs`, `node tools/check-targets.cjs`, `node tools/check-batches.cjs`, `node tools/check-slots.cjs`, `node tools/check-enemy-damage.cjs`.

## 개체 슬롯

기존 카드 슬롯으로 작동하는 새 개체가 전투 중 자동 등장합니다. 회복 주술사는 이끼 온실·봉인된 성소, 속박 술사는 봉인된 성소·심연의 옥좌, 전투 지휘관은 박쥐 병영·철벽 요새·심연의 옥좌, 잔불 정령은 잿불 화구·심연의 옥좌에 등장합니다. 주술사·사제는 같은 팀을 3초마다 치유하고 지휘관은 5초마다 분노·집중을 적용합니다. 속박 술사의 속박탄은 주변 40 안 다른 팀에 표식·속박을, 잔불 정령의 사망 장판은 6초간 다른 팀에 화상을 적용합니다. 생명의 보석은 습득 전 주변 80 안 플레이어를 치유하며 습득 시 경험치를 줍니다. 별도 기믹 버튼이나 새 카드는 추가하지 않습니다. 검증: `node tools/check-entity-gimmicks.cjs`.

플레이어의 기존 슬롯에 더해 적·아군·구조물(오브 포함)·장판·탄환·보석·아이템은 개체마다 독립된 슬롯 하나를 가집니다. **E/Tab** 카드 편집에서 상단 분류, **◀/▶**, 좌우 방향키 또는 빈 영역의 좌우 스와이프로 페이지를 넘깁니다.

각 개체의 `슬롯 주인 → 행동 카드`를 추가·삭제·재배치하거나 기본 기믹으로 복원할 수 있습니다. 이동·접촉 피해·방어·소환·사격·드롭·습득·유인·장판·분열·폭발 등은 해당 행동 카드를 제거하면 중단됩니다. 체력·위치·수명과 상태 이상 처리는 개체의 공통 속성으로 유지됩니다. 기존 치유·버프·상태 이상 등 대상에 직접 적용하는 행동 카드도 개체 슬롯에서 사용할 수 있습니다. 개체 슬롯의 기본 기믹은 자체 작동 간격을 따르며 추가한 기존 행동은 별도 쿨타임을 따릅니다.

편집은 현재 개체에 적용되고 새 개체는 기본 슬롯으로 생성됩니다. 분열한 탄환은 원본 카드 구성을 복사하되 슬롯·쿨타임은 독립됩니다. 개체 기믹 카드는 도감의 **개체 기믹** 분류에서 확인할 수 있으며 플레이어 레벨업 보상에는 등장하지 않습니다.

피해·속도는 개체의 기본 공격력·이동 속도를 기준으로 계산하며, 배율·소환 수·방어량·보상량·폭발 반경은 실제 행동 카드가 소유합니다. 사령술사와 망령 군주는 소환 카드에 각각 3체·6체를 지정하고 주기 카드로 6초·5초를 유지합니다. 카드를 다른 개체로 옮기면 수량과 배율은 카드에 유지되고 공격력 등 기본 상태만 받는 개체를 기준으로 계산합니다. 편집기의 **기믹 효과 보기**와 카드 설명에서 실제 효과를 확인할 수 있습니다.

추가 검증: `node tools/check-entity-slots.cjs`, `node tools/check-explicit-actions.cjs`.

개체의 소환·사격·아군 공격·포탑·지뢰는 **거리 조건 → 대상 → 주기 → 행동** 조합으로 구성합니다. 적의 소환·사격은 **플레이어**, 아군 공격·포탑·지뢰는 **가장 가까운 적**을 기본 대상으로 사용합니다. 가장 가까운 적은 슬롯 주인 기준 600 거리 안에서 선택합니다. 행동 카드에는 소환 수·피해·탄속·폭발 등 실제 효과만 남기고, 대상·거리·반복 간격은 각 카드에서 편집합니다. 구체와 독·점액·심연 장판, 회전 칼날의 반복 간격도 주기 카드로 분리합니다. 주기 카드를 제거하면 행동 비용에 따른 기본 쿨타임을 사용하며, 기존 조건 카드도 개체 슬롯에서 바로 뒤 대상 카드에 적용됩니다.

플레이어를 명시하던 개체 기믹은 **플레이어 대상 → 행동 → 슬롯 주인 대상**으로 연결합니다. 이동·도주·귀환·수집·미끼·폭발의 플레이어 관련 효과와 부착 장판의 이동 기준이 이에 해당하며, 플레이어 대상 카드를 빼거나 슬롯 주인으로 바꾸면 해당 행동은 실행되지 않습니다.

접촉·충돌 피해는 **슬롯 주인 → 충돌 대상: 다른 팀 → 행동**으로 구성합니다. 충돌 대상 카드는 대상 목록을 필터링하는 대신 접촉 피해·탄환 충돌의 허용 팀을 설정하며, 같은 팀·아군 팀·적군 팀·모든 팀도 선택할 수 있습니다. 플레이어·아군·설치물은 아군 팀, 적은 적군 팀, 화약통은 중립 팀이며 탄환과 분열한 탄환은 발사자의 팀을 유지합니다.

보석·자석·상자는 **플레이어와 접촉 시 → 슬롯 주인 → 흡수**로 습득합니다. 이동 후 같은 프레임에 접촉을 확인하고 보상량은 아이템 개체의 스탯을 사용합니다. 별도 습득 기믹 행동 카드는 제거했습니다. 기존 **곧 사라질 때**는 **사망 시**로 바뀌었고 별도 개체 사망 조건도 이 카드로 통합했습니다. 플레이어의 사망, 개체의 파괴·수명 만료 이벤트에서 죽은 주인까지 발동 위치로 사용해 한 번 실행하며, 남은 쿨타임과 빙결은 사망 행동을 막지 않습니다.

구체 타격·점액 지대는 **주인 범위의 적 → 주기 → 저격**, 지뢰는 **생성 후 0.5초 → 거리 58 이내 → 가장 가까운 적 → 폭발**, 소멸 폭발은 **사망 시 → 슬롯 주인 → 폭발**로 통합했습니다. 별도 기믹 행동 4종은 제거하고 피해 비율·넉백·반경·부착 대상 여부는 개체의 공통 행동 설정으로 보관합니다. 개체 슬롯의 주기 카드는 일반 행동에도 적용되며, 충돌 팀 설정은 공통 직접·범위 피해와 발사한 탄환에도 적용됩니다.

지대 흡인은 **슬롯 주인 → 소용돌이**로 통합했습니다. 소용돌이·심연 개체는 장판을 추가 생성하지 않고 매 프레임 흡인하며, 개체 범위·넉백 260% 속도·저항·중심 정지 거리 10·속박/빙결 제외·부착 시 플레이어 방향과 정지 거리 20을 유지합니다. 일반 소용돌이 카드는 기존처럼 장판을 생성합니다.

지대 밀어내기는 **슬롯 주인 → 결계**, 반경 자동 접근은 **슬롯 주인 → 끌어당기기**로 통합했습니다. 결계는 연속 모드에서 개체 범위·넉백 600% 속도·적 반경을 포함한 가장자리·최소 저항 배율 25%·부착 동작을 유지합니다. 아이템의 끌어당기기는 반경 90 감지 후 초기 역방향 이동·가속·최대 속도·자석 반응을 유지하며, 속도 수치는 개체 이동 스탯을 참조합니다.

칼날 공전 기믹은 **슬롯 주인 → 충돌 대상: 다른 팀 → 충돌 피해**로 통합했습니다. 공전 이동은 개체 설정으로 분리하고 칼날 3개·초당 4라디안·타격 반경 14·칼날별 0.2초 재타격·피해 80%·넉백 90%를 유지합니다. 충돌 피해를 제거하면 칼날은 회전만 하며, 일반 탄환은 기존처럼 대상당 한 번 타격합니다.

접촉 피해는 **충돌 피해**, 갑주 방어는 **철갑의 상시 모드**, 탄환 귀환·유도는 **부메랑·유도탄의 기존 탄환 적용 모드**로 통합했습니다. 독 지대는 **범위/부착 대상 → 주기 → 저격**, 드롭은 **사망 시 → 슬롯 주인 → 보상 소환 → 소환**으로 분리했습니다. 접촉 간격·방어 계산 순서·귀환 지연과 재타격·유도 회전 제한·보상 확률과 소환 자식의 보상 억제를 검증하며, `node tools/check-common-action-modes.cjs`로 확인할 수 있습니다.

팀 검증: `node tools/check-teams.cjs`.


Shared entity stats are moveSpeed, attackPower, maxHp and knockback. Projectile speed is independently configured on each firing card. Related action values now use stat ratios for both descriptions and execution; counts, patterns, radii, durations and rewards retain their card values. See reports/action-stat-ratios.md and run node tools/check-stat-ratios.cjs.

도주 이동은 `entityFlee`로 정의하며, 남은 도주 시간은 `escT`로 관리합니다. `수명 종료 시 → 슬롯 주인 → 소멸` 카드로 시간 조건과 제거 행동을 표현할 수 있으며, 기본 수명 만료는 이동이나 슬롯 구성과 독립적으로 처리됩니다. 도주로 소멸한 적은 사망 보상을 지급하지 않습니다.

폭발 카드는 일반 `explode` 하나로 통합했습니다. 지뢰·유성·점액·심연·소멸 탄환 모두 반경 100, 슬롯 주인 공격력 260%, 넉백 260을 사용합니다. 지뢰의 제거는 같은 조건의 별도 `소멸` 슬롯으로 정의하며, 폭발 변형의 화상·플레이어 자해·부착 대상 전용 피해는 제거했습니다. 검증: `node tools/check-common-mechanics.cjs`, `node tools/check-common-action-modes.cjs`, `node tools/check-stat-ratios.cjs`.

소환은 개체별 개별 행동으로 분류하며, 설명에는 수량과 핵심 효과만 표시합니다.
