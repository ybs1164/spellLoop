# Spell Loop

카드를 조합해 반복 발동하는 스킬을 만들고 몬스터 무리에서 살아남는 웹 게임입니다.

## 실행

저장소를 내려받은 뒤 `index.html`을 브라우저에서 열면 실행됩니다.

## 이벤트 주문

이벤트 슬롯은 자동 순환에서 빠집니다. **주문 호출**은 Space, **출발**은 이동 시작, **급정지**는 이동키를 놓을 때 실행됩니다.

**파고들기**는 적의 100 거리 안으로 진입, **치고 빠지기**는 접근한 적에게서 160 밖으로 후퇴, **현장 지휘**는 설치물의 48 거리 안으로 진입할 때 실행됩니다. 대상·행동을 연결하세요: `파고들기 → 자신 → 참격`, `치고 빠지기 → 후방 지점 → 지뢰`, `현장 지휘 → 설치물 → 사출`.

이벤트 카드의 코스트는 0이며 슬롯 쿨타임은 최소 1.5초입니다. 쿨타임 중 입력은 1초 동안만 기다리고, 키를 길게 눌러도 반복 호출되지 않습니다. **E/Tab**은 카드 편집, **Esc**는 일시정지입니다.
