# reports

- 개체·카드 감사: `entity-*.md`, `slot-card-ui-audit.md`, `action-stat-ratios.md`
- 밸런스: `balance-*.md|json|csv`, `stage-balance-patch.md` (`tools/simulate-balance.cjs`·`summarize-balance.cjs` 가 이 폴더에 직접 쓴다)
- 자동 플레이 기록·체크포인트: `generated/`
