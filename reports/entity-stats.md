# 기본 스탯 적용 목록

공통 스탯은 **이동 속도, 기본 공격력, 최대 체력, 넉백** 네 가지입니다. 넉백 기본값은 100이며 끌어당기는 거리의 기준으로 사용합니다. 타격 넉백과 탄속은 시전자 스탯과 독립적으로 카드에 지정합니다. 비율 전체 목록은 [행동 카드 스탯 비율](action-stat-ratios.md)에 있습니다.

- 적은 생성 시 이동 속도에 기존 ±10% 편차, 체력·피해에 스테이지 배율이 적용됩니다.
- 플레이어 공격력 10은 기존 주문 피해의 기준값입니다. 공격력을 20으로 바꾸면 주문 피해가 2배가 되며, 기본값에서는 기존 피해를 유지합니다.
- 기본 공격력은 모든 카드 피해의 기준입니다. 지뢰와 화약통의 기준 공격력을 10으로 지정해 각각 400%, 450% 폭발 피해로 기존 기본 피해 40, 45를 유지합니다.
- 소환체 체력·공격력·이동 속도는 시전자 스탯을 따릅니다. 위 표는 플레이어 기본값 100·10·170에서 생성할 때의 값입니다. 포탑 탄속 460은 카드에 별도로 지정하며 이동 속도와 독립적입니다.
- 투사체 이동 속도는 생성 시 속도 벡터의 길이, 공격력은 생성 시 피해값입니다. 장판의 공격력·이동 속도는 생성 시 시전자 값을 사용하며, 예를 들어 독 장판은 공격력 60%씩 0.5초마다 피해를 줍니다. 아이템의 이동 속도 기준은 170이고, 현재 이동 속도는 별도로 가속 처리합니다.
- 체력은 기존 값을 연결했으며 체력 없는 개체에 체력 기능을 추가하지 않습니다.
- 카드 편집기(E/Tab)의 플레이어 및 개체 항목에 기본 스탯을 표시합니다.

투사체 넉백은 생성 시 지정한 값이 기본 스탯이 되며, 이후 투사체 이동 속도를 바꿔도 넉백은 유지합니다. 적 탄환의 기존 넉백 0도 유지합니다.
