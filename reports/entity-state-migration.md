# 개체 상태와 행동 카드 전환

상태는 최대 체력·현재 체력·이동 속도·공격력·넉백·범위·위치·남은 수명 등 개체 자체의 상태를 의미하며, 행동은 슬롯에 편성된 실제 행동 카드를 의미한다.

`mechanicStats`, `stateValues`, `actionSettings`, `orbitSettings` 같은 개체별 세부 수치 저장소는 모두 제거했다. 숫자 사전을 다른 이름으로 유지하지 않는다.

| 기존 세부 항목 | 대체 원본 |
| --- | --- |
| 이동 속도·기본 피해·체력·넉백·범위 | 개체 기본 상태 |
| 피해 배율·원소·타격 넉백·재타격 간격·관통 | 저격·충돌 피해 행동 카드 |
| 탄속·발수·발사 패턴·탄환 수명·발사 위치 | 마탄 행동 카드 |
| 폭발 피해·반경·인화·실행 후 소멸 | 폭발 행동 카드 |
| 소환 종류·수량·사망 자식·경험치·아이템 보상 | 소환·오브 스폰 행동 카드 |
| 방어량·정면 방어·원소 배율·상태 내성 | 철갑·정면 방어·원소 취약·상태 저항 행동 카드 |
| 귀환 대기·감속·회수 거리·유도 회전 | 부메랑·유도탄 행동 카드 |
| 흡인·밀어내기·접근 속도와 가속 | 소용돌이·결계·끌어당기기 행동 카드 |
| 칼날 수·회전 속도·칼날 반경 | 새 공전 행동 카드 |
| 팀·감지 거리·반복 주기·생성 후 대기 | 공통 조건·대상·주기 카드 |

행동 카드의 효과 값이 실행의 원본이다. 같은 행동 카드 두 장에 서로 다른 배율이 있으면 각 장의 값을 사용하고, 다른 개체로 옮기면 카드의 배율은 유지하면서 받는 개체의 공격력 등 기본 상태를 기준으로 계산한다. 카드를 제거하면 효과도 사라지며, 공전도 별도 행동 카드 제거로 멈춘다. 도감은 기본 상태와 실제 카드 체인을 표시하고 별도 세부 수치 패널은 표시하지 않는다.

카드 정의는 중첩 값까지 불변으로 공유하며 편집은 해당 개체의 카드 ID를 교체한다. 동일 카드 정의를 재사용하므로 생성 개체마다 수치 사전이나 카드 정의를 누적하지 않는다. 실제 실행 중인 카드의 문맥을 사용하므로 같은 개체의 여러 슬롯과 플레이어의 카드 실행도 서로의 설정을 가져오지 않는다.

`bossActions`는 일반 `slotRecipes`로 전환했다. 모든 개체 슬롯은 같은 실행부를 사용하며 `gimmick`, `targetTeam`, `targetRange`, `actionPeriod` 같은 특별 슬롯 속성은 없다. 보스·기믹의 팀·범위·주기는 실제 카드로 편성한다. 주기 카드를 제거하면 공통 행동 쿨타임을 사용한다.

검증: 전체 `tools/check-*.cjs` 18종. 추가 검증은 `tools/check-entity-card-values.cjs`이며 저장소 부재, 서로 다른 카드 값, 카드 이동·제거, 독립 편집, 불변 정의 재사용, 공전 중단, 플레이어 실행, 도감 표시를 확인한다.
