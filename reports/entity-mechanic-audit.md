# 개체 기믹 행동 전체 감사

최신 전환 결과는 [개체 상태와 행동 카드](entity-state-migration.md)를 참고한다. 개체별 세부 수치 저장소는 제거했고 기본 상태 외의 수치는 실제 행동 카드가 소유한다. 아래의 ‘개체 스탯에 보관’ 제안은 이전 설계 기록이다.

## 적용 결과

현재 추가 통합: `entityVortex`, `entityWard`, `entityAttract`, `entityBlades`, `entityContact`, `entityArmor`, `entityReturn`, `entityHoming`, `entityPoison`, `entityDrop`도 삭제했다. 각각 소용돌이·결계·끌어당기기·충돌 피해·철갑·부메랑·유도탄·저격/폭발·소환으로 실행하며, 연속/상시/기존 탄환 적용 모드와 인화 이벤트·보상 소환 제어로 기존 동작을 보존한다. 이하 전체 표는 변경 전 설계 기록이다. 검증: `node tools/check-common-action-modes.cjs`, `node tools/check-mechanic-migrations.cjs` 및 전체 `tools/check-*.cjs`.

추가 통합 완료: `entityAttack`, `entityShoot`, `entitySummon`, `entityDeathSplit`, `entityAbyss`를 카드 등록·도감 설명·전용 실행부에서 삭제했다. 아군 근접은 거리/가장 가까운 적/주기/저격, 화살과 적 조준·원형 사격은 거리/대상/주기/마탄으로 실행한다. 생존 소환은 행동 가능 조건/거리/플레이어/주기/소환, 사망 자식 생성은 사망 시/슬롯 주인/소환으로 실행한다. 심연은 범위 또는 부착 대상/주기/저격과 기존 지대 흡인을 함께 사용한다. 개체별 행동 설정으로 피해 배율·탄속·수명·형태·발수·패턴·소환 종류를 보존하고, 격려 배율·초기 아군 공격 대기·소환 보상·사망 자식 넉백·팀을 검증했다. `node tools/check-mechanic-migrations.cjs`로 추가 통합을 검증한다. 아래 전체 표의 이 항목들은 과거 설계 기록이다.

추가로 `entityOrb`, `entitySlime`, `entityMine`, `entityDeathBlast` 4종을 삭제하고 공통 `snipe`/`explode`와 범위·거리·활성화·주기·사망 조건으로 대체했다. 기존 `entityCollect`까지 합쳐 삭제된 행동은 5종이다. 이하 표는 변경 전 감사 기록이며 아직 적용하지 않은 통합 후보도 포함한다.

`ifExpiring`은 이름과 의미를 **사망 시**로 바꾸고 별도 `entityOnDeath` 카드는 삭제했다. 개체와 플레이어 사망 모두 죽은 주인을 위치 기준으로 한 번 실행하며 쿨타임·빙결을 무시한다. 거리·방향은 슬롯 주인 기준, 상태 판정은 직접 상태·점화·화염 특성을 포함하도록 수정했고 주변 적 판정에서 자기 자신을 제외했다. 대상 수는 살아 있는 선택 대상으로 계산한다. 일반 개체 행동에도 주기 및 충돌 팀 설정이 적용된다. 점액/구체 범위 피해는 이동·수명 처리 후 실행하며 개체가 같은 프레임에 소멸하면 생존 시 피해를 실행하지 않는다.

현재 `ENTITY_EFFECT_DEFAULTS`의 남은 행동 30종과 삭제된 습득 1종을 확인했다. 아래 조합은 최적화 설계이며, 기존 코드에 그대로 꽂아도 같은 동작이 된다는 뜻은 아니다. 조건·대상·실제 효과를 분리하고, 피해·반경·속도·종류 같은 차이는 개체 스탯으로 유지하는 기준으로 판단했다.

## 조건 카드 자체의 확인 결과

| 현재 조건 | 확인한 문제 / 사용 가능 범위 |
|---|---|
| 부상일 때 / 체력 절반 이하·초과 | 대상 체력을 검사하므로 직접 재사용 가능. 발동자의 체력과 효과를 받는 대상의 체력을 따로 지정하려면 조건 기준 대상 분리가 필요. |

| 앞에 있을 때 | 플레이어 facing 기준 위치 조건. 개체 facing/ang 지원과 피격 방향 이벤트 조건은 각각 필요. |

현재 카드에 없는 조건: 피격 시, 점화 시, 생성 후 n초, 점화 후 n초, 범위 진입 시, 같은 대상 재타격 가능 시, 들어온 피해 원소/방향 조건. README의 '위기·포위 17종' 설명과 달리 기본 filter 정의는 15종이다.

## 공통 실행부에서 먼저 해결할 사항

1. 조건 기준을 플레이어 고정에서 슬롯 주인/지정 대상 기준으로 확장하고 상태 조회를 legacy timer와 directStates 공통 함수로 묶는다.
2. 일반 행동에도 주기 카드와 개체 스탯의 피해·반경·넉백·탄속 등 설정을 연결한다. 카드별 수치 변형을 새 카드로 늘리지 않는다.
3. 일반 발사 행동은 actionActor로 피해 스탯과 source 팀을 선택하지만 `shoot`의 좌표와 `bolt`의 조준 각도는 여전히 플레이어 기준이다. 저격 directAction도 player.stats.might와 플레이어 연출 기준을 별도로 사용한다. 발동자 기준으로 통일해야 한다.
4. 장판 범위 전체, 접촉 대상, 부착 대상, 추적 대상 같은 선택을 대상 카드로 표현한다. 기존 '적'은 플레이어 중심 600 범위이고 '가장 가까운 적'만 슬롯 주인 중심 600이다.
5. 조건 평가 → 대상 선택 → 시간 제어 → 원자 효과를 공통 실행한다. 매 프레임 연속 효과, 슬롯 단위 반복, 대상/칼날별 재타격 시간, 사망 이벤트 일회 실행을 별도로 보존한다.

## 통합 순서

1. 점액 지대·구체 타격·근접 타격을 공통 직접 피해로, 소멸 폭발·지뢰 폭발을 공통 폭발로 통합한다.
2. 조준/원형 사격·화살·포탑을 공통 발사로, 살아 있을 때 소환과 사망 시 자식 생성을 공통 소환으로 통합한다.
3. 심연의 피해/흡인을 분해하고, 지대 흡인·밀어내기·자동 접근을 공통 이동 효과의 설정으로 통합한다.
4. 점화·귀환·도주에 포함된 이벤트/시간 조건을 분리하고, 갑주와 철갑의 방어 효과를 통합한다.
5. 공전·유인·저항·원소 배율 같은 고유 원자 효과는 남기되 그 안의 대상 선택·조건·반복 타이머 중복을 제거한다.

적용 결과에 명시한 4종 외의 통합 후보는 각 항목의 세부 동작과 검증을 보존하며 추가 통합해야 한다.

도주 이동과 수명 종료: `entityFlee`는 도주 이동을 정의한다. `수명 종료 시 → 슬롯 주인 → 소멸`은 `ifLifetimeEnded → entitySelf → disappear`로 구성되며, 남은 도주 시간은 `escT`를 참조한다. 기본 수명 만료는 이동과 슬롯 구성에 독립적으로 처리된다. 관련 검증은 `node tools/check-entity-slots.cjs`에서 수행한다.
