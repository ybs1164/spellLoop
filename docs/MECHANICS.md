# Amagos — 상세 규칙·개발 노트

넉백 저항과 기본 수명은 모든 개체의 공통 스탯이며, 수명은 카드 없이도 만료됩니다. 플레이어는 편집·확장 슬롯과 별도로 매 프레임 화살표/WASD 입력을 실행하는 고정 이동 슬롯을 가집니다. 화약통의 자동 점화·연쇄 반응·기본 사망 폭발은 제거했으며, 분열 복제는 원본의 현재 카드 스택을 계승하고 슬롯과 게이지 저장소를 독립적으로 가집니다. 플레이어 분신도 입력 이동과 스킬을 계승하되 기본 수명은 10초입니다. 검증: `node tools/check-basic-state-inheritance.cjs`.

개체 세부 수치 저장소를 제거하고 최대 체력 같은 기본 상태와 실제 행동 카드로 대체했습니다. 피해 배율·탄속·발수·공전·보상은 카드가 소유하며, 보스·기믹도 같은 이벤트·대상·행동 규칙으로 실행합니다. 전환 기준: [개체 상태와 행동 카드](../reports/entity-state-migration.md).

3단계 진행 · 보스 스테이지 8종: 한 판은 1 → 2 → 3단계로 진행하고, 단계마다 해당 단계 스테이지 중 하나가 무작위로 정해집니다. 보스를 쓰러뜨리면 다음 단계로 넘어가고 3단계 보스를 쓰러뜨리면 승리합니다. 1단계 슬라임 둥지(슬라임 왕·분열) · 이끼 온실(재생의 모체·회복) · 박쥐 병영(군단의 지휘자·격려) / 2단계 망자의 묘역(망령 군주·소환) · 봉인된 성소(속박의 예언자·표식·속박) · 철벽 요새(철벽의 수문장·방패·갑주) / 3단계 잿불 화구(잿불의 폭군·화염 탄막) · 심연의 옥좌(심연 군주·갑주 탄막). 출현 배너와 일시정지 화면에서 빌드별 공략 힌트를 확인할 수 있습니다. 검증: `node tools/check-gimmick-bosses.cjs`.

카드를 조합해 반복 발동하는 스킬을 만들고 몬스터 무리에서 살아남는 웹 게임입니다.

## 실행

저장소를 내려받은 뒤 `index.html`을 브라우저에서 열면 실행됩니다.

## 슬롯 실행

플레이어·적·아군·설치물·장판·탄환·아이템 모두 스탯과 여러 슬롯을 가지며, 각 슬롯은 **이벤트 카드 최대 1장 → 대상 카드 → 행동 스택**으로 구성합니다. 두 번째 이벤트를 넣는 편집은 거부하며 카드가 사라지지 않습니다. 이벤트를 비우면 매 프레임 한 번 실행을 시도합니다. 대상이 없거나 첫 행동이 적용 불가능하면 실행하지 않습니다.

쿨타임과 행동별 대기 저장소는 제거했습니다. 슬롯 게이지는 기본 최대 60이며 0.1초마다 1씩(초당 10) 감소합니다. 실행 비용은 60을 넘겨 쌓일 수 있고, 60을 넘긴 초과분은 초당 1씩만 감소합니다. 실행마다 `1 × (아군 대상 수 + 적군 대상 수 × 2) × 슬롯 행동 카드 게이지 값의 곱`만큼 증가하고(행동 카드의 `gauge`, 지정이 없으면 카드 코스트), 마지막 실행은 최대치를 넘길 수 있습니다. 적군은 `hostile` 팀 또는 적 대상, 그 외는 아군으로 셉니다. 포화된 슬롯은 다음 실행 비용만큼 여유가 생기면 다시 실행하며, 포화 중 발생한 이벤트는 저장하지 않습니다. 충돌 유지·상시 방어 같은 연속 행동은 게이지를 쓰지 않으며, 입력 이동·개체 이동(추적·거리 유지·도주 포함) 같은 이동 행동만 있는 슬롯은 움직이는 동안 초당 1씩 게이지를 써서 포화 시 멈추고, 다른 행동 카드와 합치면 일반 실행 비용을 써서 매 프레임 실행되지 않습니다. 이벤트 카드는 슬롯 옵션을 줍니다: 사망 시 최대 +100, 수명 종료 시 +75, 기폭 시 +75, 피격·생성·획득 시 +50, 효과 적용 시 +25(+회복 ×1.1) / 타격 ×1.25, 처치 ×1.5, 행동 완료·이동 완료 ×1.2, 회복 시 ×1.3 회복 속도. 집중은 게이지 회복을 1/0.65배로 가속합니다. 슬롯의 이벤트 카드가 n장이면 게이지 냉각 속도(초과분 포함)가 2^n배가 됩니다. 일시정지·편집 중에는 게임 시간과 회복도 멈춥니다.

일반 이벤트 카드는 피격·사망·수명 종료·생성·타격·처치·회복·획득·효과 적용·이동 완료·행동 완료 이벤트를 사용합니다. 체력·거리·방향·주변 적·표식·멈춤·화상·강적·대상 수 상태 이벤트는 조건이 유지되는 동안 반복 실행합니다(게이지가 빈도를 제한). 한 슬롯에 이벤트 카드를 여러 장 넣을 수 있으며, 발동 이벤트(피격·주기 등)는 하나라도 일어나면 실행하고 상태 이벤트는 모두 만족하는 대상만 남기는 조건이 됩니다. 주기 이벤트는 일반 이벤트 카드 하나로 통합되어 보관함·슬롯에서 카드 안의 숫자 입력(0.1~30초, 0.1초 단위)로 주기를 조절하며, 명시된 시간마다 실행하고, 주기 이벤트가 없는 행동에 숨은 반복 간격을 적용하지 않습니다. 개체 기본 거리·팀 제한은 대상 선택 카드에 포함됩니다.

행동 스택은 첫 행동만 실행합니다. 나머지는 첫 행동이 만든 개체나 효과의 이벤트 슬롯에 들어갑니다. `마탄 → 번개 → 폭발`은 마탄 타격마다 번개를 실행하고 번개의 각 타격마다 폭발합니다. 소환·포탑은 기본 공격의 타격(발사체 포함), 독·화상은 실제 피해 주기, 지뢰는 기폭 사망, 미끼·보호막·철갑은 피격, 보상 생성은 획득, 분열은 복제체 생성, 소용돌이·결계는 실제 이동, 나머지는 행동 성공 완료에 연결됩니다. 연계 슬롯도 독립된 게이지를 가집니다.

공격은 이벤트 상대와 위치를 사용하며, 치유·강화는 행동 주체를 기본 대상으로 합니다. 죽은 상대는 마지막 위치를 전달합니다. 소환수 자신의 연계 피해는 기본 공격 타격으로 재전달하지 않습니다. 이벤트는 순서가 보존되는 큐로 처리하고 한 번에 2048개까지 처리하며 남은 이벤트는 다음 처리로 넘깁니다. 순환 이벤트의 깊이는 32로 제한합니다.

이미 생성된 개체는 생성 당시 행동 스택을 유지합니다. 카드 편집은 게이지를 초기화하지 않으며, 분열은 현재 게이지를 복사하되 독립 저장합니다. 같은 타격의 중복 처리, 습득 중복, 사망 중복은 차단합니다.

시작 코스트 포인트 5, 레벨업당 1포인트, 슬롯 확장 3포인트(최대 6개), 슬롯 제한 코스트 강화 규칙은 유지합니다. **E/Tab**은 편집, **Esc**는 일시정지입니다. HUD·편집기·개체 조회에서 슬롯 게이지와 이벤트 구성을 확인할 수 있습니다.

검증: `node tools/check-event-slots.cjs` (실행·게이지·이벤트 제한·타격/소환/화상 연계·사망/수명/획득·복제·편집기), `node tools/check-debuffs.cjs`, `node tools/check-drain.cjs`, `node tools/check-action-target-positions.cjs`.

## 개체 슬롯

개체의 기본 이동·접촉 피해·방어·소환·발사·획득·사망 보상은 독립된 슬롯으로 구성합니다. 이동과 상시 기믹은 이벤트 없이, 사격·소환·지원은 주기 이벤트로 실행합니다. 지뢰의 기폭과 제거도 독립된 이벤트 슬롯입니다. 기본 행동을 제거하면 해당 동작이 멈춥니다.

개체 조회는 I 키로 열며, 각 개체의 슬롯과 게이지를 펼쳐 볼 수 있습니다. 개체 변형 카드의 피해·탄속·범위는 카드 배율과 개체 스탯으로 계산하고, 생성된 개체는 생성 원인의 이벤트 연계 슬롯을 추가로 가집니다. 기본 행동·소환체·투사체도 플레이어와 같은 이벤트 실행기를 사용합니다.
