# Amagos — 상세 규칙·개발 노트

넉백 저항·상태 저항과 기본 수명은 모든 개체의 공통 스탯이며, 빙결·속박·공포는 지속시간을 합산하되 기본 상한(빙결 3초·속박 4초·공포 4초) × (1 - 상태 저항)을 넘지 않고, 넉백·끌어당김·소용돌이·결계·공포 이동 같은 강제 이동은 (1 - 넉백 저항) × (1 - 상태 저항)배로 받습니다(보스 80%, 정예 25%, 그 외 0%). 수명은 카드 없이도 만료됩니다. 플레이어의 첫 슬롯은 `바람의 장화`(=0.016)로 매 프레임 화살표/WASD 입력을 실행하는 이동 슬롯입니다. 화약통의 자동 점화·연쇄 반응·기본 사망 폭발은 제거했으며, 분열 복제는 원본의 현재 카드 스택을 계승하고 슬롯과 쿨타임을 독립적으로 가집니다. 플레이어 분신도 입력 이동과 스킬을 계승하되 기본 수명은 10초입니다. 검증: `node tools/check-basic-state-inheritance.cjs`.

개체 세부 수치 저장소를 제거하고 최대 체력 같은 기본 상태와 실제 행동 카드로 대체했습니다. 피해 배율·탄속·발수·공전·보상은 카드가 소유하며, 보스·기믹도 같은 아티팩트·대상·행동 규칙으로 실행합니다. 전환 기준: [개체 상태와 행동 카드](../reports/entity-state-migration.md).

3단계 진행 · 보스 스테이지 8종: 한 판은 1 → 2 → 3단계로 진행하고, 단계마다 해당 단계 스테이지 중 하나가 무작위로 정해집니다. 보스를 쓰러뜨리면 다음 단계로 넘어가고 3단계 보스를 쓰러뜨리면 승리합니다. 1단계 슬라임 둥지(슬라임 왕·분열) · 이끼 온실(재생의 모체·회복) · 박쥐 병영(군단의 지휘자·격려) / 2단계 망자의 묘역(망령 군주·소환) · 봉인된 성소(속박의 예언자·표식·속박) · 철벽 요새(철벽의 수문장·방패·갑주) / 3단계 잿불 화구(잿불의 폭군·화염 탄막) · 심연의 옥좌(심연 군주·갑주 탄막). 출현 배너와 일시정지 화면에서 빌드별 공략 힌트를 확인할 수 있습니다. 검증: `node tools/check-gimmick-bosses.cjs`.

카드를 조합해 반복 발동하는 스킬을 만들고 몬스터 무리에서 살아남는 웹 게임입니다.

## 실행

저장소를 내려받은 뒤 `index.html`을 브라우저에서 열면 실행됩니다.

## 슬롯 실행

플레이어·적·아군·설치물·장판·탄환·아이템 모두 스탯과 여러 슬롯을 가지며, 각 슬롯은 **아티팩트 카드 → 대상 카드 → 행동 스택**으로 구성합니다. 플레이어 슬롯은 6개로 고정이고 맨 앞이 이동 슬롯(`바람의 장화 → 플레이어 → 입력 방향 이동`)입니다. 슬롯 포인트·슬롯 코스트·카드 코스트는 없습니다.

모든 슬롯은 쿨타임으로 작동합니다. 쿨타임은 기본 1초에서 시작해 슬롯 카드마다 붙은 쿨타임 연산(`+`, `−`, `×`, `=`)을 **배치 순서대로**(아티팩트 → 대상 → 행동, 칸 안에서는 왼쪽부터) 적용한 값이며 0.016초보다 짧아지지 않습니다. 결과가 `=0.016` 이하이면 매 프레임 작동합니다. 준비된 슬롯은 대상이 있을 때 즉시 작동하고 쿨타임을 다시 겁니다(넘친 시간은 다음 쿨타임에서 뺍니다). 대상이 없으면 쿨타임을 쓰지 않습니다. 집중 버프는 쿨타임 감소 속도를 1/0.65배로 높입니다. 카드 편집은 남은 쿨타임을 유지하되 새 쿨타임을 넘지 않게 줄이고, 분열·복제는 현재 남은 쿨타임을 복사해 독립 저장합니다. 일시정지·편집 중에는 쿨타임도 멈춥니다. HUD·편집기·개체 조회는 슬롯마다 `남은 시간 / 쿨타임`을 쿨타임 아이콘과 함께, 카드는 아래쪽에 자기 연산을 표시합니다.

아티팩트는 슬롯 안의 변수에 제약을 거는 카드이며, 제약이 카드 본문 설명입니다. 구성 제약(예: `바람의 장화` 이동 카드가 있는 슬롯 전용 =0.016, `절제의 반지` 행동 카드 3장 이하 ×0.6, `외길의 인장` 행동·대상 1장씩 −0.45)은 어기는 편집을 거부하고, 작동 조건(`질주의 깃털` 이동 중 ×0.6, `고요의 모래시계` 정지 중 ×0.5, `피의 성배` 체력 절반 이하 ×0.4, `포위의 뿔피리` 주변 적 3 이상 ×0.55)은 조건이 거짓이면 작동하지 않으며, 발동 순간(`가시 갑옷` 피격 시 −0.5, `공명의 종` 다른 슬롯 작동 시 ×0.55)은 그 순간에 쿨타임이 끝나 있을 때만 작동합니다. 한 슬롯에 여러 장을 넣을 수 있습니다.

개체 수 안전 상한: 분열은 대상 종류별 개체 수가 상한(적 400, 아군·설치물·장판 120, 탄·아이템 400) 이상이면 실행하지 않습니다. 같은 팀·같은 종류의 장판이나 설치물 위에 같은 장판·설치물을 다시 만들면 새로 만들지 않으며(「전체」 대상이 자기가 만든 장판에 장판을 겹쳐 끝없이 늘리는 것 방지), 종류별 장판·설치물은 150개를 넘으면 가장 오래된 것이 끝납니다.

기존 이벤트 카드는 개체 기믹 유지에 필요한 것만 개체 전용 아티팩트로 남겼습니다: 사망·타격·피격·생성·행동 완료·획득·이동 완료·기폭 시(행동 스택 연계와 사망 보상), 플레이어 접촉·사거리 내 적 진입 시, 부상·시야·사거리·범위·거리·팀 조건, 충돌 대상 팀. 주기·체력·거리·방향·표식·멈춤·화상·강적·대상 수 이벤트와 주기 카드는 삭제했습니다. 개체의 공격·소환·지원 주기는 행동 카드의 `=주기` 연산(행동 칸이 마지막이라 앞 연산을 덮어씀)으로, 이동·충돌·방어 같은 기믹과 상시 효과는 `=0.016`으로 표현합니다.

행동 스택은 첫 행동만 실행합니다. 나머지는 첫 행동이 만든 개체나 효과의 연계 슬롯에 들어갑니다. `마탄 → 번개 → 폭발`은 마탄 타격마다 번개를 실행하고 번개의 각 타격마다 폭발합니다. 소환·포탑은 기본 공격의 타격(발사체 포함), 독·화상은 실제 피해 주기, 지뢰는 기폭 사망, 미끼·보호막·철갑은 피격, 보상 생성은 획득, 분열은 복제체 생성, 소용돌이·결계는 실제 이동, 나머지는 행동 성공 완료에 연결됩니다. 연계 슬롯은 부모 슬롯의 쿨타임을 따르므로 자기 쿨타임이 없고, 사망 시 슬롯도 쿨타임을 보지 않습니다.

공격은 이벤트 상대와 위치를 사용하며, 치유·강화는 행동 주체를 기본 대상으로 합니다. 죽은 상대는 마지막 위치를 전달합니다. 소환수 자신의 연계 피해는 기본 공격 타격으로 재전달하지 않습니다. 이벤트는 순서가 보존되는 큐로 처리하고 한 번에 2048개까지 처리하며 남은 이벤트는 다음 처리로 넘깁니다. 순환 이벤트의 깊이는 32로 제한합니다.

이미 생성된 개체는 생성 당시 행동 스택을 유지합니다. 같은 타격의 중복 처리, 습득 중복, 사망 중복은 차단합니다. 레벨업·보물 상자마다 카드 5장 중 하나를 고릅니다. **E/Tab**은 편집, **Esc**는 일시정지입니다.

검증: `node tools/check-event-slots.cjs` (쿨타임·연산 순서·매 프레임 기믹·아티팩트 제약/조건/발동·타격/소환/화상 연계·획득·복제·편집기), `node tools/check-slots.cjs`, `node tools/check-debuffs.cjs`, `node tools/check-drain.cjs`, `node tools/check-action-target-positions.cjs`.

## 개체 슬롯

개체의 기본 이동·접촉 피해·방어·소환·발사·획득·사망 보상은 독립된 슬롯으로 구성합니다. 이동과 상시 기믹은 `=0.016`(매 프레임), 사격·소환·지원은 행동 카드의 `=주기` 쿨타임으로 실행합니다. 이 `=주기` 변형 카드는 개체 전용이라 보상으로 나오지 않습니다(가중치 0). 지뢰의 기폭과 제거도 독립된 이벤트 슬롯입니다. 기본 행동을 제거하면 해당 동작이 멈춥니다.

개체 조회는 I 키로 열며, 각 개체의 슬롯과 쿨타임을 펼쳐 볼 수 있습니다. 개체 변형 카드의 피해·탄속·범위는 카드 배율과 개체 스탯으로 계산하고, 생성된 개체는 생성 원인의 이벤트 연계 슬롯을 추가로 가집니다. 기본 행동·소환체·투사체도 플레이어와 같은 이벤트 실행기를 사용합니다.
